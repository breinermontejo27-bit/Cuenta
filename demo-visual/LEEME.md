# Orisma 2.0 · Demostración visual (propuesta, no es la app)

Prototipo navegable de la propuesta visual final, con datos de ejemplo. **No forma parte de la aplicación**:
no se carga desde `index.html`, no está en la lista de precarga (`src/precache-list.js`) y no toca datos.

- Versión publicada para revisar en el teléfono: página privada de claude.ai (enlace en la conversación).
- Para verla en local: abrir `index.html` con un servidor (`python3 -m http.server`) y entrar a `/demo-visual/`.
- Rama: `claude/orisma-ajuste-visual`, creada desde `claude/account-code-restructure-fe1fqc` (`7a7872d`,
  versión 2.0.0-rc.1). Para volver atrás basta con usar esa rama o ese commit: no se ha modificado.
